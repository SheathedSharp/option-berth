# 第三方源码与许可

[English](third-party.md) | 中文

这个仓库确实使用了第三方软件：Go 模块是依赖库，GSAP 被复制到站点中，Playwright 用于站点开发检查。引擎早期还参考过 Sonar。删掉声明，并不能消除代码的来源和相应义务。

## 仓库里存了什么

| 材料 | 去哪里看 | 用途 |
|---|---|---|
| 固定版本源码目录 | [third_party/README.md](../third_party/README.md) | 组件版本、用途、源码包、校验和更新方法 |
| 机器可读清单 | [sources.json](../third_party/sources.json) | 输入锁文件的哈希、来源和归档完整性信息 |
| 原始源码包 | [sources/](../third_party/sources/) | 真正的上游源码，不是只有许可证和网址的空目录 |
| 必要的第三方声明 | [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) | 版权归属及分发时的责任 |
| 现有发布许可输入 | [go-runtime-licenses.txt](../third_party/go-runtime-licenses.txt) | 二进制打包使用的许可原文；范围比源码清单窄 |

源码保留为压缩包，不直接展开在仓库里。这样既能校验原始快照，也不会让 Go 把复制进来的包当成本项目代码。它们方便开发者查看和继续开发，不是另一个模块代理。构建仍按未改动的 `engine/go.mod`、`engine/go.sum` 解析依赖，没有启用 `vendor`，也没有添加 `replace`。

## 范围和“完整”的含义

引擎清单覆盖 Go 模块解析选中的整个依赖图，包括间接依赖、测试和生成工具依赖；另外标出了 macOS、Linux、Windows 的 amd64、arm64 六种目标实际生产导入的并集。被依赖图选中，不代表一定链接进每个平台的二进制。

Go 模块 ZIP 是对应版本的完整模块快照，不等于整个上游项目。有可信缓存时，保留 ZIP 并核对 `go.sum` 的 h1 校验值。每个选中模块也都有官方上游的源码包，以 tag 或 commit 固定版本，再记录归档的 SHA-256。部分模块 ZIP 不在本机缓存中，公共 Go 代理又超时；这些组件已有完整上游源码，但不能声称它们与模块 ZIP 做过逐文件或 h1 等价验证。

SQLite 要分两层看：引擎用的是 modernc 生成的 Go 实现，不是系统 SQLite 动态库。归档同时保留该模块源码和相应版本的原始 SQLite 源码。站点 GSAP 文件会与固定上游包里的同一文件比较。Playwright 源码覆盖站点锁文件中的三个包，不包含浏览器二进制。

这里不是一台 CI 机器的完整复制品。操作系统库、另行下载的浏览器、托管 Actions、外部 coding agent 和模型服务仍属于运行环境。工具链和构建工具的边界在清单中说明。Git 历史不是源码内容，不归档；如果出现未取到的 submodule 或 Git LFS 内容，必须明确报告，不能称为完整。

## 怎样查看或继续开发

先做离线完整性检查，不运行任何下载代码：

```sh
python3 scripts/check_third_party.py
```

从清单中找到组件和准确版本，先查看包内文件，再用支持路径和链接安全过滤的工具展开到**本工作树之外的新目录**。保留原始许可证、声明和文件头。只是看源码，不需要运行上游的安装钩子、脚本或测试；要构建或修改第三方项目，应另按它自己的开发前提开展。

有意变更依赖后，按下面的流程刷新：

```sh
python3 scripts/collect_third_party.py --collect
python3 scripts/check_third_party.py
```

收集器只读取官方公开来源和已经校验的模块缓存，不安装依赖，不改变构建如何找包。提交前检查版本、来源网址、commit 或 tag、哈希和许可变化。下载缺失必须记为缺口，不能用空目录冒充成功。清单由脚本生成，不应手改清单来掩盖检查失败。

## 许可和历史来源如何处理

GSAP 使用自己的标准“不收费”许可，不适用本项目的 MIT，也不能擅自认定为 OSI 开源许可。仓库保留原始文件头和官方许可网页快照，并说明抓取日期，不把当前网页伪装成带历史版本的法律文本。

Sonar 记作历史来源，不算当前运行依赖。这里保守保留其原始 MIT 版权及完整许可；代码相似率不是删除版权声明的法律依据。这也不表示当前每个引擎文件都派生自 Sonar。

独立的 macOS 客户端自己维护字体和终端依赖；本仓库不分发这些资产，也不把它们复制进来，具体边界见第三方声明。来源不明就标为不明，不替它随意指定许可证。
