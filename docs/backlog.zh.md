## 需要持续取得的证据

| 方向 | 判断完成的依据 |
| --- | --- |
| 编程助手的可用性 | 对应 provider、场景、版本的完整输入和输出；不能把一次成功推广到其他助手 |
| 比较与性能结论 | 同条件对照、重复次数和区间；失败预检不能产生成功表格 |
| 平台支持 | 各目标上的原生测试；交叉编译不能替代 Windows/Linux 实机运行 |
| 观察与事件恢复 | 成功系统扫描、真实变化与游标重放；受限沙箱中的连接冒烟不够 |
| 版本切换与存储 | 固定旧版生产写者、新版拥有者、失败释放与只读路径的对抗证据 |

这些是验收要求，不是在此断言某次发布未跑过；请核对对应提交的 CI 和报告。[验证指南](agent/validation.md)说明证据等级，[发布规范](agent/releasing.md)规定发布门槛。本次文档整理不执行真实服务或模型，也不补造这些结果。

## 不随待办扩大范围

本项目不因此接管外部服务、自动修改编排工具设置或替人批准模型建议。缺少观察权限先报告未知，不能绕过沙箱。应用数据的删除始终由人决定。

配套 skill 由自己的仓库维护；跨协议修改需要协调，但不能用修改本仓测试的方式假装对方已适配。
