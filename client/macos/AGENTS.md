# macOS 客户端开发约定

产品边界见 [产品定义](../../docs/product.md)，构建和验证入口见 [README](README.md)。

- 客户端呈现 CLI/daemon 的事实，不新增独立运行模型；Jev 只属于可选外部 adapter。
- 界面修改后运行冻结状态渲染并查看图片。菜单、确认框、悬停和窗口交互另做原生检查，
  不把离屏渲染当作已覆盖。真实数据检查使用隔离 BERTH_HOME 和自建项目。
- 布局随窗口伸缩，分隔线保持可拖动及合理命中区。颜色、字号和动效使用既有令牌，
  遵守减弱动态效果设置；列表刷新不增加扰动动画。
- 文本快捷键必须保留复制、粘贴、全选和撤销；菜单裁剪不能破坏文本编辑。
- 端口与 PID 按标识符显示，不插入千位分隔符；解析日志前处理终端控制码。
- ImageRenderer 不能覆盖 ScrollView、文本编辑控件或独立窗口；冻结呈现与真实交互分开验收。
- 不提交真实用户截图、日志、凭证或本机路径。示例及录制夹具必须合成或脱敏。
- 不修改或子集化随附 Monaspace 字体；分发时保留 OFL 与原版权。
- 没有进行的视觉、网络、起停或安装验证，明确标注未运行。
