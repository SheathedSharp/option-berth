option-berth 指南

一个 checkout 该跑什么，是不是真的在跑，没跑为什么。这本指南讲清 oberth 每条命令背后那条事实链。

安装 oberth 先看事实链
worktree 清单 服务 运行 运行事实

oberth status · hello-worktree

hello-worktree · main

api      running   :21730   health 200
worker   running   no port

2 services · manifest oberth.yaml

两个服务。一个没有端口。两个都在运行。

为什么有这本指南

worktree 解决了并行写代码，没有解决并行运行。四个 checkout，四个猜测。一条事实链替掉它们。

一条链，五个站点

每个站点只由一个角色写入。下一个站点只读上一个站点发布的东西——不再有第二个状态来源。

worktree

代码观察路径与 Git 身份：仓库、分支、脏文件数。其他一切都挂在这个根上；一次运行永远不会属于它没有在其中启动的 checkout。

读这一章

oberth status --json

{ "worktree": {
  "root": "/work/hello-worktree",
  "identity": "wt_0123456789ab"
} }

清单

人写 oberth.yaml；agent 可以起草，只有人能采纳。清单声明服务、端口、依赖和健康检查——不从正在运行的进程里猜。

读这一章

oberth.yaml · hello-worktree

name: hello-worktree
services:
  - name: api
    cmd: python3 -u api.py
    port: auto
    health: /health
  - name: worker
    cmd: python3 -u worker.py
    depends_on: [api]

服务

一条声明说清跑什么、用哪个端口、依赖谁、怎么检查。port: auto 让每个 checkout 拿到自己的地址，而不是共享一个猜测。

读这一章

oberth up --wait

api      started   :21730   ready
worker   started   no port

运行

后台进程记录一次运行：pid、起止时间、退出码和日志路径。无端口 worker 仍然是一次运行——它只是没有监听。

读这一章

oberth logs worker --once

worker: API health=200
worker: API health=200
worker: API health=200

运行事实

代码观察此刻为真的事实：活着、在监听、健康、最近一次退出原因。这是四种事实，一种不能推出另一种；读不到的表永远不会被写成“没在运行”。

读这一章

oberth status · hello-worktree

api      running   :21730   health 200
worker   running   no port

核心闭环

人读表格；agent 用 --json 读同一条命令。一个接口，两个读者。

这本书

核心闭环是四条命令。其余章节把它撑开：声明、并行 worktree、交接、JSON、边界。

两个读者，一个接口

如果你是个人

装一次，确认一次清单，然后读表格。整条闭环都是同一组命令。

oberth status
oberth up --wait
oberth logs api --once
从安装开始

如果你是 coding agent

用 --brief 开局，用 --wait 启动，从当前运行里读失败。每次读取都是 stdout 上的一个 JSON 值。

oberth status --json --brief
oberth up --wait --json
oberth logs api --once --json --run current --first-error
读 JSON 里的运行事实

两个读者用同一条命令。没有第二个接口，没有 MCP server，内核里也没有模型。llms.txt 把这本书列给机器读。

这本指南不是什么

不是契约。确切的 CLI 表面、JSON 字段和清单规则在 docs/cli.md。这本指南讲事实链，并把你送到那里。

不是产品官网。官网展示产品；这里是给需要读懂它的人和 agent 的长篇手册。

不是某个框架的教程。示例用 Hello Worktree，因为它只靠 Python 3 就能跑；同一条链适用于任何技术栈。

从一条命令开始。

安装引擎，然后读第一个 checkout。在你采纳清单之前，不会往你的项目里写任何东西。

install · macOS 或 Linux

curl -fsSL https://raw.githubusercontent.com/SheathedSharp/option-berth/main/install.sh | sh
