Every command has one machine shape: one JSON value on stdout, diagnostics on stderr, stable error codes. The same command answers a person and an agent. Only the reader changes.

The rules

  • With plain --json, stdout holds exactly one JSON value. Diagnostics go to stderr and never mix into it.
  • Streaming commands use NDJSON, one value per line.
  • Exit codes are 0 for success, 1 for a run failure, 2 for an argument or option error, and 130 when Ctrl-C interrupts the command.
  • An error is {"error":{"code":"…","message":"…","hint":"…"}}. The hint points at evidence that really exists.
  • No wire field is accepted without being read. A published field is a promise every client may rely on, so the protocol build fails on a field that no handler acts on.

A worked read

A partial success is still one value. This up --json started one service and failed the other; the exit code is 1, and both outcomes are in the same document.

state
started, skipped or failed: the result of the start action, not a readiness claim.
reason
A stable, branchable failure reason such as start_failed, port_occupied or ready_timeout.
hint
A deterministic next step that points at evidence which exists. It names the service's logs only if the process really came up, and the dependency's logs when a dependency was not ready. When there is no executable step, it stays empty.
port_holder
Present on port_occupied: the port, pid, command and kind of the holder, plus the managed group, service name and run id when the holder is one of ours.
ready
The CLI's annotation, not a daemon fact. It is true after --wait confirms readiness, and false when no wait was requested. false is not a failure.

What an absent field does not mean

Absent is not zero and not false. An absent observation means the listener table was usable; an absent running_services means “not observed”, not 0. An observation code does not mean “nothing is listening”, and unknown is not success. When a fact cannot be read, the document says so instead of filling the gap with a default.
